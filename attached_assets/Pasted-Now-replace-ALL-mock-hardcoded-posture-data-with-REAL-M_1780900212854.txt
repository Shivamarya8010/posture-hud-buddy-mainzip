REAL SCORING LOGIC — runs every frame
━━━━━━━━━━━━━━━━━━━━━━━━
Every frame MediaPipe returns landmarks. Run these 3 checks:

── CHECK 1: HEAD TILT ──
Compare current ear Y difference vs calibration baseline.
currentEarDiff = Math.abs(landmark7.y - landmark8.y)
headTiltDeviation = currentEarDiff - calibration.earLevelDiff
If headTiltDeviation > 0.03 → HEAD FAILING
Penalty = Math.min(30, headTiltDeviation * 600)
Alert message: "Level your head — it's tilting to one side"

── CHECK 2: FORWARD LEAN ──
currentNoseToShoulderX = nose.x - midpoint of (shoulder11.x + shoulder12.x) / 2
forwardDeviation = Math.abs(currentNoseToShoulderX - calibration.noseToShoulderMidX)
If forwardDeviation > 0.04 → HEAD FAILING (forward lean)
Penalty = Math.min(40, forwardDeviation * 500)
Alert message: "Look up a bit! Your head is leaning forward 👀"

── CHECK 3: SCREEN DISTANCE ──
currentEarDistance = pixel distance between landmark7 and landmark8
distanceRatio = currentEarDistance / calibration.earDistance
If distanceRatio > 1.25 → TOO CLOSE — penalty up to 30
If distanceRatio < 0.75 → TOO FAR — penalty up to 20
Alert message too close: "Move back from the screen a bit"
Alert message too far: "Move closer to the screen"

── CHECK 4: SHOULDER LEVEL ──
currentShoulderDiff = Math.abs(landmark11.y - landmark12.y)
shoulderDeviation = currentShoulderDiff - calibration.shoulderLevelDiff
If shoulderDeviation > 0.03 → SHOULDERS FAILING
Penalty = Math.min(30, shoulderDeviation * 600)
Alert message: "Straighten your shoulders — one is higher than the other"

── FINAL SCORE CALCULATION ──
Start score at 100
Subtract each failing check's penalty
Final raw score = 100 - total penalties
Clamp between 0 and 100

Score smoothing — REQUIRED:
Keep array of last 15 frame scores
Display score = average of last 15 scores
This prevents the number from jumping around
